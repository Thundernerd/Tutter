## Get the sounds

Download the sound pack used in this tutorial: [tiny-racers-sounds.zip](./files/tiny-racers-sounds.zip). Unzip it into your project so the files end up in a `sounds/` folder. Godot imports `.wav` files automatically.

| File | Used for |
| --- | --- |
| `engine.wav` | A short buzzing loop for the engine |
| `skid.wav` | A noisy loop for tyre squeal |
| `bump.wav` | A thud for collisions |
| `beep.wav`, `go.wav` | The countdown |
| `lap.wav`, `finish.wav` | Completing a lap, finishing the race |

They're generated by a small Python script, nothing fancy. For your own, [jsfxr](https://sfxr.me) makes retro effects in the browser.

## Looping sounds

The engine and skid sounds must loop seamlessly. A WAV file can carry its own loop points, and these two do, so Godot imports them as looping: select `engine.wav` and look at the **Import** dock, where **Loop Mode** is *Detect From WAV*. For a sound without loop points, set **Loop Mode** to **Forward** there and click **Reimport**.

:::note[Why the engine loop doesn't click]
The engine buzz is exactly 45 cycles of a 90 Hz wave in half a second, so the end of the file joins its start perfectly. A loop that cuts a wave in half gives an audible click every time it repeats.
:::

## The engine

Engine sound is the best speedometer there is: you *hear* when you're flat out, and when the off-road has dragged you down. Add an `AudioStreamPlayer2D` named `EngineSound` to `car.tscn`:

| Property | Value |
| --- | --- |
| Stream | `sounds/engine.wav` |
| Volume dB | `-10` |
| Max Distance | `2000` |
| Bus | `SFX` |

`AudioStreamPlayer2D` pans and fades with distance from the camera, so a car on the left of the screen sounds left. The big max distance keeps every car on screen audible.

```gdscript title="car.gd" ins={1,6-8,16,19-22}
@onready var engine_sound: AudioStreamPlayer2D = $EngineSound


func _ready() -> void:
	$Visuals/Body.color = color
	# Only players get engine noise: four engines at once is a lot of buzzing.
	if is_player():
		engine_sound.play()

# ...

func _physics_process(delta: float) -> void:
	# ...
	move_and_slide()
	_handle_collisions(impact_velocity)
	_update_effects()


func _update_effects() -> void:
	var speed := velocity.length()
	if is_player():
		engine_sound.pitch_scale = 0.7 + 1.3 * clampf(speed / max_speed, 0.0, 1.2)
```

`pitch_scale` plays the sound faster (higher) or slower (lower). At a standstill the engine idles at 0.7× pitch; at top speed it screams at 2×. The clamp allows a little above top speed, for when a pool ball kicks you faster than the engine could.

:::tip[CPU engines]
Only players' cars hum. With four cars on screen, four engines turn into a drone that drowns out yours, and yours is the one that tells you something. Try enabling them for everyone and decide for yourself.
:::

## Race sounds

In `race.tscn`, add a plain `Node` named `Sounds` with four `AudioStreamPlayer` children, all on the `SFX` bus: `Beep` (`beep.wav`), `Go` (`go.wav`), `Lap` (`lap.wav`) and `Finish` (`finish.wav`). These aren't positional: they're announcements, so they play at the same volume everywhere.

Then play them at the right moments:

```gdscript title="race.gd" ins={5,13,17,24,33,42,46}
func _start_countdown() -> void:
	state = State.COUNTDOWN
	_count = 3
	hud.show_message(str(_count), 0.8)
	$Sounds/Beep.play()
	countdown_timer.start()


func _on_countdown_timer_timeout() -> void:
	_count -= 1
	if _count > 0:
		hud.show_message(str(_count), 0.8)
		$Sounds/Beep.play()
		return
	countdown_timer.stop()
	hud.show_message("GO!", 0.8)
	$Sounds/Go.play()
	# ...


func _complete_lap(car: Car) -> void:
	# ...
	if car.is_player():
		$Sounds/Lap.play()
		if Settings.submit_lap(Session.track().id, lap_time):
			# ...


func _finish(car: Car) -> void:
	# ...
	if not car.is_player():
		return
	$Sounds/Finish.play()
	# ...


func _end_round(winner: Car) -> void:
	# ...
	if points[w] == START_POINTS * 2:
		state = State.FINISHED
		hud.show_message("%s wins!" % winner.driver_name, 2.0)
		$Sounds/Finish.play()
		end_timer.start()
	else:
		hud.show_message("%s takes the point" % winner.driver_name, 2.0)
		$Sounds/Lap.play()
		round_timer.start()
```

Also give the options screen's `TestSound` the `bump.wav` stream, so the effects slider has something to play.
