title: Menus
summary: A main menu, a pause menu, and game over and victory screens.
---

You built your first UI scene for the level complete screen. The rest of the menus use the same few containers:

| Container | Does |
| --- | --- |
| `CenterContainer` | Centres its child |
| `VBoxContainer` / `HBoxContainer` | Stacks children vertically / horizontally |
| `GridContainer` | Lays children out in rows of N columns |
